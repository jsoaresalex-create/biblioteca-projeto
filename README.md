# Sistema de Gerenciamento de Aluguel de Livros

Projeto desenvolvido como desafio técnico para o bootcamp de desenvolvimento web da Avanade.

## Sobre o projeto

Sistema web para gerenciamento de aluguel de livros, com cadastro de livros, registro de aluguéis e controle de devoluções.

## Estrutura

- `BibliotecaAPI` — back-end em C# com ASP.NET Core e SQL Server
- `biblioteca-frontend` — front-end em Angular

## Como rodar

Consulte o README de cada pasta para instruções detalhadas de execução.

## Tecnologias

- C# / ASP.NET Core
- Entity Framework Core
- SQL Server
- Angular 19
- TypeScript
