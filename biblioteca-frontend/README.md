# Biblioteca Frontend

Interface web para gerenciamento de aluguel de livros, desenvolvida com Angular.

## Tecnologias

- Angular 19
- TypeScript
- HTML / CSS

## Como rodar

### Pré-requisitos

- Node.js instalado
- Angular CLI instalado (`npm install -g @angular/cli`)
- API do back-end rodando em `http://localhost:5062`

### Passos

1. Clone o repositório
2. Abra o terminal na pasta do projeto
3. Instale as dependências: npm install
4. Rode a aplicação: ng serve
5. Acesse no navegador: http://localhost:4200
## Funcionalidades

### Livros
- Listar todos os livros
- Cadastrar novo livro
- Editar livro
- Excluir livro
- Visualizar status (disponível ou alugado)

### Aluguéis
- Listar todos os aluguéis
- Registrar novo aluguel
- Registrar devolução de livro
- Excluir aluguel
